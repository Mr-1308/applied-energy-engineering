# References

## Primary learning resources

- DTU Mathematics 1a: https://math1a.compute.dtu.dk/ — official course materials and assessment guidance.
- Marta Victoria, photovoltaic engineering textbook companion: https://martavp.github.io/pv-textbook/intro.html — PV theory and applied examples.
- pvlib Python documentation: https://pvlib-python.readthedocs.io/en/stable/ — solar position and PV performance modelling.
- PyPSA project: https://pypsa.org/
- PyPSA documentation: https://docs.pypsa.org/stable/ — energy systems, dispatch, storage, power flow and capacity expansion.
- Linopy documentation: https://linopy.readthedocs.io/ — mathematical optimisation and custom constraints.
- HiGHS: https://highs.dev/ — open-source optimisation solver.
- SymPy documentation: https://docs.sympy.org/
- NumPy documentation: https://numpy.org/doc/
- SciPy documentation: https://docs.scipy.org/doc/scipy/
