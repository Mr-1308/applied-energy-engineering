# Learning library

Free, original study materials for mathematics, Python and hybrid renewable energy engineering. No university account or paid course is required for the materials here. These are independent resources, not official DTU coursework.

## Available now

- [Module 00 — Mathematics and Python foundations](00_mathematics_python_foundations.ipynb): eight lessons, mathematical derivations, worked code examples and unsolved exercises.
- [Diagnostic assessment](../00-mathematical-foundations/diagnostic.ipynb): independent baseline test.
- [Applied Case 001 — PV string power and energy](../00-mathematical-foundations/case_001_pv_string.ipynb): first practical assignment.
- [Teaching and assessment protocol](../TEACHING_PROTOCOL.md): review, correction and publication criteria.

## Study workflow

Pull the latest repository changes, launch JupyterLab locally, open the workbook and save an independent working copy outside the public checkout for private submissions. Run worked examples, then solve exercises manually and develop your own code. Submit for tutor review before publishing approved development and validated results. Do not publish personal diagnostic records, private discussions or confidential project data.

See [the curriculum](../CURRICULUM.md) and [PyPSA track](../PYPSA_TRACK.md) for the full roadmap.
